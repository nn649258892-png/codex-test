# 数研 · 福彩3D与排列三选号工作台

纯静态中文选号研究工具，无安装依赖，不接收投注。

## 功能

- 福彩3D / 体彩排列三分别管理历史记录和收藏。
- 单选/直选、组选三、组选六完整枚举；组选正确去重。
- 定位、号码池、和值、跨度、奇偶、大小、012路、必含/排除筛选。
- 候选集分布、成本和理论覆盖率；随机不重复抽样、CSV 导出。
- 历史 CSV/TXT 导入（按旧到新排列）、频次、遗漏统计。
- 本地方案收藏与还原；技巧解释和原文来源。

## 运行

需要 Node.js 18+。执行 `node server.cjs`，访问 http://127.0.0.1:4173 。也可用任意静态服务器托管 `dist/`。

执行 `node tests.cjs` 检查算法。`dist/` 可直接作为静态网站部署目录。

## 数据与计算边界

不内置虚构开奖，不自动获取开奖。历史数据和方案仅保存在当前浏览器 localStorage；切换浏览器/域名不共享数据。清除浏览器数据会清除保存内容。

理论概率基于 000–999 等可能且各期独立的假设。筛选不会改变具体号码的概率。组选三 90 个不同组合，各覆盖 3 个有序结果；组选六 120 个不同组合，各覆盖 6 个有序结果。单倍成本按每注 2 元计算，不含倍投或派奖，未实现奖金收益预测。

012 路按余数无序组合筛选；大小以 5 为界；频次按全部位置计数，遗漏按任一位置均不出现计期。所有历史记录需要用户自行核实。
